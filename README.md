# 答疑悬浮球

一个常驻 Windows 桌面的学习答疑悬浮球。遇到不会的题，把题目粘进去按 Ctrl+Enter，
它调用 DeepSeek 把答案流式显示出来。专为做 U 校园（Unipus）读写教程 / 视听说教程的练习设计。

## 启动

双击 **`启动悬浮球.vbs`**（无黑框）。若想看到日志窗口，用 `启动悬浮球.bat`。

启动后屏幕右下角会出现一个蓝色圆形“答”字球。

## 用法

1. 在 U 校园页面上选中题目，`Ctrl+C` 复制
2. 单击悬浮球 → 展开面板
3. 面板题目框里 `Ctrl+V` 粘贴
4. 按 `Ctrl+Enter` 作答（或点“作答”按钮）
5. 答案实时显示在下方，同时自动追加到 `答案记录.md`

| 操作 | 方式 |
| --- | --- |
| 展开面板 | 单击悬浮球 |
| 收起成球 | 面板右上角 `✕`，或右键菜单“收起成悬浮球” |
| 拖动位置 | 按住球体/面板顶栏拖动（位置会记住） |
| 随时开关工具 | `Ctrl+Alt+U` 全局热键，或右键菜单“显示/隐藏” |
| 右键菜单 | 切换形态、答案风格、模型、刷新 key、退出 |
| 退出 | 右键菜单“退出” |

### 三种形态

- **悬浮球**：默认，最小遮挡
- **宽面板**：题面 + 答案分栏，适合长文
- **窄条**：一行输入 + 三行答案，适合边看网页边用

### 答案风格

右键 → 答案风格，三选一。默认“答案 + 一行解析”：

- **只要答案**：最简短，选择题只给字母
- **答案 + 一行解析**：给字母 + 一句话说明考点（默认）
- **答案 + 完整解析**：含干扰项分析，适合复盘错题

## 听力题怎么用

悬浮球看不到也听不到你的音频，所以听力题要**你手动补一句听力原文**：

```
听力原文：
W: I'm afraid I can't make it to the meeting tomorrow.
M: No problem, we'll fill you in on Monday.
Question: What does the man offer to do?
A. Cancel the meeting
B. Take notes for her
C. Move the meeting
D. Call her tomorrow
```

U 校园听力一般有文字稿（部分单元在“听力原文/Transcript”按钮里，或用播放器的字幕）。
把原文和题目一起贴上，正确率会高很多。只有选项没有原文时，模型会回“不确定”。

## 配置

首次启动就会在本目录生成 `config.json`（不用等退出）：

```json
{
  "mode": "brief",
  "model": "deepseek-chat",
  "api_key": "",
  "hotkey": "ctrl+alt+u",
  "log_answers": true,
  "ball_pos": [1180, 620]
}
```

- `api_key`：留空则自动读取 DSH 凭证库里的 DeepSeek key（当前就是这么用的）。
  想换成自己的 key，填这里并重启。也支持环境变量 `DEEPSEEK_API_KEY`。
- `model`：`deepseek-chat`（快）或 `deepseek-reasoner`（推理题更准，稍慢）。
- `log_answers`：设为 `false` 则不再记录答案。

> 退出请用右键菜单的“退出”。从任务管理器强杀进程也能正常关掉，只是悬浮球位置不会更新，
> 其余设置（每次改动时已即时保存）不受影响。

## 这个工具不做什么

说明白，避免误解：

- **不自动答题**。它不会去点 U 校园的按钮、不会填答案、不会提交。
  每次提问都要你手动按 Ctrl+Enter，答案也只是显示在屏幕上，抄不抄、怎么用由你决定。
- **不碰 U 校园的页面**。没有浏览器插件、没有注入脚本、没有模拟你的登录态。
  它和 U 校园网站之间没有任何数据往来。
- **不做反检测伪装**。没有指纹伪造、没有行为模拟、没有隐藏自动化特征——
  因为它本来就不自动化。它就是一个普通的桌面置顶窗口，用普通的 API 调用问问题。

## 关于怎么用它才合适

这是个答疑工具，定位是**帮你搞懂不会的题**，不是帮你交作业：

- **建议**：先自己做，卡住了再问；看到答案后回头想一遍为什么；错题用“答案 + 完整解析”
  模式再过一遍；考前把 `答案记录.md` 当错题本翻。
- **提醒**：U 校园的必修练习通常计入课程成绩，直接照抄答案属于学术不诚信，
  被查到的后果（成绩作废、纪律处分）由你自己承担。这个工具的默认设置
  （显示解析、记录答案）也是按“辅助理解”而不是“无脑抄”来设计的。
- 如果某道题它答错了，右键切到 `deepseek-reasoner` 再问一次通常能纠正。

## 常见问题

**按 Ctrl+Alt+U 没反应？**
热键被别的软件占了。编辑 `config.json` 把 `hotkey` 改成比如 `"ctrl+alt+k"` 再重启。

**提示“没有可用的 API key”？**
右键 → 刷新 API key。若仍失败，说明 DSH 凭证库里的 key 已失效或换位置了，
直接在 `config.json` 的 `api_key` 字段填一个自己的 DeepSeek key。

**提示 HTTP 402？**
DeepSeek 账户余额不足，去 platform.deepseek.com 充值。

**答非所问 / 说“不确定”？**
大多是选项没复制全，或听力题没给原文。重新复制时把题干和所有选项一起选上。

**球拖到屏幕外面看不见了？**
按 `Ctrl+Alt+U` 隐藏再显示，会自动回到屏幕内。

## 文件说明

| 文件 | 作用 |
| --- | --- |
| `tutor_ball.py` | 主程序（单文件，只用 Python 标准库） |
| `启动悬浮球.vbs` | 静默启动（推荐） |
| `启动悬浮球.bat` | 带控制台启动，方便看报错 |
| `config.json` | 配置（首次启动自动生成） |
| `答案记录.md` | 问答记录，可当错题本 |
| `预览-*.png` | 三种形态的界面截图，可以删 |

环境要求：Windows + Python 3.9 以上（当前用 Python 3.14）。不需要 pip 安装任何东西。
